# Handmade products ecommerce store
- The app follows an MVC architecture.
- Built with Node.js + Express
- Pug for templating, Prisma as ORM
- Database: PostgreSQL
- Includes health checks to monitor system status and ensure every service is communicating as it should.
- Provides an admin panel that allows management of products and orders.
- Implements a verification step before checkout to confirm that each product is valid and available.
---
# Tech stack
- Runtime: Node.js + Express.js
- Views: pug (SSR)
- Styling: Tailwind CSS (CDN)
- Database: PostgreSQL on supabase + prisma ORM
- Media Hosting: Cloudinary
- Emailing system: ...
- Auth: Passport.js (local strategy, no OAuth or OpenID connect) + bcrypt
- Security: Helmet, CSRF, rate limiting, zod validation
